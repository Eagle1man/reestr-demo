# Карта технического задания

Соответствие требований ТЗ версии 1.0 от 06.10.2026 конкретным местам в коде.
Документ отвечает на вопрос «где в системе реализовано требование ТЗ» и
используется при приёмке.

Обозначения: **реализовано** — работает и проверено; **частично** — работает не
полностью, ограничение указано; **схема готова** — структура данных есть,
эксплуатационная часть ждёт решения.

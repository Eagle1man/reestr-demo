# Описание публичного API

Позиция 9 комплекта поставки (п.15 ТЗ). Предварительный публичный API описан в
разделе 9.4 ТЗ.

---

## 1. Назначение

Раздел «Наука» официального сайта — **публичная витрина**. Реестр —
**операционный источник данных**. Сайт не хранит и не редактирует вторую копию
карточки (п.9.1 ТЗ). Прямое подключение сайта к рабочей базе запрещается.

API отдаёт только опубликованные и разрешённые поля. Закрытых сведений в ответе
нет физически, а не «скрыто на стороне клиента».

---

## 2. Адреса (п.9.4 ТЗ)

```
GET /api/public/v1/programs
GET /api/public/v1/programs/{id}
GET /api/public/v1/projects
GET /api/public/v1/projects/{id}
GET /api/public/v1/results
GET /api/public/v1/results/{id}
```

Дополнительно (вне перечня ТЗ, для удобства интеграции):

```
GET /api/public/v1/manifest     описание контура и правил
GET /api/public/v1/stats        счётчики публичных данных
GET /api/public/v1/             краткая справка
OPTIONS /api/public/v1/*        предварительный запрос CORS
```

**Только чтение.** Методы записи отсутствуют: `POST`, `PATCH`, `PUT`, `DELETE`
возвращают 405.

Идентификатор `{id}` принимается как внутренний UUID или как читаемый код
(`РНП-2026-0001`, `РЕЗ-2026-0001`).

---

## 3. Формат ответа

JSON в кодировке UTF-8. Даты — в формате ISO 8601 (`2026-10-08`), дополнительно
для дат доступны поля `start_date` и `end_date` в формате `ДД.ММ.ГГГГ`.

### Заголовки ответа

| Заголовок | Значение |
|---|---|
| `Content-Type` | `application/json; charset=utf-8` |
| `Content-Language` | `ru` |
| `Cache-Control` | `public, max-age=300` |
| `X-RateLimit-Limit` | Предел запросов в минуту с адреса |
| `X-RateLimit-Remaining` | Остаток |
| `X-Registry-Generated-At` | Момент формирования ответа |
| `X-Registry-Version` | `v1` |

### При превышении лимита

```http
HTTP/1.1 429 Too Many Requests
Retry-After: 60
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 0
```

Заголовки лимита присутствуют и в ответе с отказом: клиенту нужно знать величину
лимита даже тогда, когда запрос не обслужен.

## 5. Проекты

### `GET /api/public/v1/projects`

Параметры: `program` (код или UUID), `year`, `status`, `q`, `limit` (1–200),
`offset`.

```json
{
  "data": [
    {
      "code": "РНП-2026-0001",
      "title": "Адаптивные методы управления качеством образовательных услуг",
      "short_title": "Адаптивное управление качеством",
      "public_annotation": "Исследование проверяет, снижает ли адаптивный контроль…",
      "status": "ST-07",
      "status_title": "Активен",
      "route": "simplified",
      "start_year": "2026",
      "end_year": "2028",
      "start_date": "08.10.2026",
      "end_date": "31.12.2028",
      "program": {"code": "НП-01", "title": "…", "short_title": "…"},
      "keywords": ["адаптивный", "контроль", "качество", "преподаватель"],
      "published": true,
      "team": [
        {"full_name": "Иванов И. И.", "role": "leader", "role_title": "Руководитель",
         "position": "доцент", "work_place": "Южный университет (ИУБиП)"}
      ],
      "results": [
        {"code": "РЕЗ-2026-0001", "type": "methodology", "title": "Методика…",
         "description": "…", "stage": "accepted", "year": "2026",
         "identifiers": {"doi": "10.1234/example"}}
      ],
      "materials": [{"title": "Отчёт", "url": "https://…"}]
    }
  ],
  "meta": {"total": 3, "limit": 50, "offset": 0,
           "filters": {"program": "НП-01"}, "generated_at": "2026-10-08"},
  "notice": "Передаются только опубликованные и разрешённые поля (SEC-03)"
}
```

Поля `team`, `results`, `materials` присутствуют в зависимости от режима
публикации проекта:

| Режим (A-15) | Что передаётся |
|---|---|
| `none` | Ничего — проект не выдаётся |
| `project` | Карточка проекта, открытая команда, открытые материалы |
| `results` | Только подтверждённые результаты |
| `all` | И то и другое |

### Что передаётся (п.9.2 ТЗ)

Номер, название, публичная аннотация, программа, открытый статус, год и сроки,
ключевые слова, утверждённые сведения о руководителе и команде, подтверждённые
результаты, ссылки на открытые материалы.

### Что не передаётся никогда

Внутренние комментарии, экспертные заключения, история согласований, риски,
ресурсные запросы, персональные контакты, закрытые файлы, конфиденциальные
сведения о партнёрах, журнал действий.

Механизм — **белый список полей**, а не чёрный: новое поле, добавленное в
карточку, не попадёт в публичный контур, пока его явно не внесут в список. При
смене состава карточки публичная выдача не «потечёт» сама.

### `GET /api/public/v1/projects/{id}`

Возвращает карточку в объекте `data`.

Неопубликованный объект возвращает **404, а не 403**: код 403 подтвердил бы
существование закрытой карточки.

## 6. Результаты

### `GET /api/public/v1/results`

Параметры: `type`, `year`, `limit`, `offset`.

```json
{
  "data": [
    {
      "code": "РЕЗ-2026-0001",
      "type": "methodology",
      "title": "Методика адаптивного контроля качества",
      "description": "Методика расчёта адаптивного интервала…",
      "stage": "accepted",
      "year": "2026",
      "identifiers": {"doi": "10.1234/example", "url": "https://…"},
      "projects": [{"code": "РНП-2026-0001", "title": "…"}]
    }
  ],
  "meta": {"total": 1, "limit": 50, "offset": 0, "generated_at": "2026-10-08"}
}
```

Результат выдаётся, только если: есть разрешение на публикацию, результат
отмечен публичным, стадия — принят, опубликован или внедрён (подтверждённые
результаты, п.9.1 п.3), и результат не связан с проектом, имеющим ограничения
по конфиденциальности.

В списке проектов у результата — только те, что разрешены к публикации.

---

## 7. Ограничение частоты

По умолчанию **60 запросов в минуту** с одного адреса. Настраивается
параметром `PUBLIC_RATE_LIMIT_PER_MINUTE`.

За адрес принимается значение `X-Forwarded-For` — это позволяет различать
посетителей сайта при обращении через обратный прокси. При превышении
возвращается 429.

Дополнительно обратный прокси дублирует ограничение на уровне nginx
(`limit_req`), чтобы отсекать поток до обращения к приложению.

Если интеграция упирается в лимит — сначала проверьте кеширование. Ответ уже
снабжён `Cache-Control: public, max-age=300`, а данные меняются редко: панель
публичной витрины вполне может обновляться раз в пять минут.

---

## 8. Разрешённые домены

Задаются параметром `PUBLIC_ALLOWED_ORIGINS` (список через запятую). При
настройке приложение добавляет заголовок `Access-Control-Allow-Origin`.

Если параметр не задан, заголовок не добавляется — браузерная интеграция с
другого домена работать не будет, что является безопасным поведением по
умолчанию.

Способ интеграции с действующей CMS согласуется после обследования (вопрос 9
ТЗ). До согласования доступны два варианта:

1. **Регламентная выгрузка** — периодический вызов API и вставка данных в CMS.
2. **Ссылка на публичную зону** реестра по адресу `/public` с адаптивной
   вёрсткой от 360 пикселей.

---

## 9. Снятие с публикации

Отзыв разрешения немедленно исключает объект из выдачи (FR-34). Кеш клиента
может сохранить данные до истечения `max-age` — при срочном снятии достаточно
уменьшить `PUBLIC_CACHE_SECONDS` или удалить кеш на стороне сайта.

Отмену публикации фиксирует журнал аудита: группа «публикация», действие
«Снятие публикации результата», с автором, временем и основанием.

## 10. Пример интеграции

### Получение списка опубликованных проектов

```bash
curl -s "https://science.iubip.ru/api/public/v1/projects?limit=100" | \
  python -c "
import json, sys
data = json.load(sys.stdin)
for p in data['data']:
    print(p['code'], '|', p['title'], '|', (p.get('program') or {}).get('title'))
print('Всего:', data['meta']['total'])
"
```

### Обработка отказа

```python
import httpx

response = httpx.get("https://science.iubip.ru/api/public/v1/projects", timeout=30)

if response.status_code == 200:
    payload = response.json()
    remaining = int(response.headers.get("X-RateLimit-Remaining", 0))
    if remaining < 10:
        print(f"Осталось запросов: {remaining} — стоит уменьшить частоту")
elif response.status_code == 404:
    # Объект не опубликован. 404 не означает ошибку интеграции:
    # снятый с публикации объект тоже возвращает 404.
    pass
elif response.status_code == 429:
    retry_after = int(response.headers.get("Retry-After", 60))
    print(f"Пауза {retry_after} с")
```

## 11. Проверка контракта

```bash
# Манифест: состав контура и правила
curl -s https://science.iubip.ru/api/public/v1/manifest | python -m json.tool

# Счётчики
curl -s https://science.iubip.ru/api/public/v1/stats

# Проверка кодировки и заголовков
curl -sI https://science.iubip.ru/api/public/v1/projects | grep -Ei 'charset|content-language|ratelimit'

# Проверка, что запись не принимается
curl -s -X POST https://science.iubip.ru/api/public/v1/projects -H 'Content-Type: application/json' -d '{}'
# Ожидается 405
```

Автоматическая проверка отсутствия закрытых полей в публичной выдаче входит в
`backend/scripts/smoke.py`: скрипт проверяет, что в ответе нет полей
`confidentiality`, `resource_request`, `review_id`, `risk_level`, `ip_note`,
`internal_comments` и прочих запрещённых п.9.2.

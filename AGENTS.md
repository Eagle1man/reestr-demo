# AGENTS.md — правила для агентов, работающих с проектом

**Реестр научных проектов Южного университета (ИУБиП)** — ТЗ 06.10.2026 v1.0.
Бэкенд: FastAPI + SQLite (`backend/`), фронтенд: React SPA (`frontend/`),
развёртывание: `deploy/`, документы поставки: `docs/` (11 позиций п.15 ТЗ).

## Память отдела

**Перед работой по этому проекту вызывай `recall`** — уроки отдела,
накопленные по нему же. Сервер хранилища подключён в `.mcp.json`
(файл локальный, в поставку не входит), имя проекта —
`reestr-nauchnyh-proektov` (файл `.om-project`).

Что уже известно и на что наступали: проверка комплектности обязана видеть
поля, заданные при создании (иначе карточка не выходит из «Черновика»);
генерация номера проекта — только внутри транзакции; публичная проекция
собирается по белому списку полей; в SQLite `lower()` работает только с
ASCII, поэтому кириллический поиск идёт по нормализованному столбцу.

После работы запиши то, что иначе придётся выяснять заново: `remember` —
неочевидное решение, `record_work` — что сделал.

## Правила проекта

- Статус `done` — только когда работа реально выполнена и проверена.
- Проверка перед сдачей: `pytest backend/tests`, `smoke.py`, `check_ui.py`,
  `tsc --noEmit`, `npm run build` — все пять без ошибок.
- Пароли и ключи в репозиторий не попадают: `SECRET_KEY`, `SEED_PASSWORD` и
  `SEED_ADMIN_PASSWORD` задаются переменными окружения.
